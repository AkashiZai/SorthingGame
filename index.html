สรุป Sorting Algorithms & Big-O

Sorting Algorithm คือขั้นตอนวิธีในการเรียงลำดับชุดข้อมูลให้อยู่ในลำดับที่ต้องการ แต่ละอัลกอริทึมมีประสิทธิภาพต่างกันดังนี้:

Algorithm Best Case Average Case Worst Case Space Complexity
Bubble Sort O(n) O(n²) O(n²) O(1)
Selection Sort O(n²) O(n²) O(n²) O(1)
Insertion Sort O(n) O(n²) O(n²) O(1)
Quick Sort O(n log n) O(n log n) O(n²) O(log n)

1. Bubble Sort

เปรียบเทียบคู่ข้อมูลที่อยู่ติดกัน (Adjacent pairs) สลับที่เมื่อตัวหน้ามากกว่าตัวหลัง ค่าที่มากที่สุดจะลอยไปท้ายแถวทีละรอบ

2. Selection Sort

ค้นหาค่าน้อยที่สุด (Minimum) จากส่วนที่ยังไม่เรียง แล้วสลับมาไว้ที่ตำแหน่งเริ่มต้นของรอบเสมอ มีจำนวนการ Swap ต่ำสุดเพียง O(n) ครั้ง

3. Insertion Sort

หยิบสมาชิกทีละตัว (Key) แล้วเลื่อนตัวที่มากกว่าไปทางขวาเพื่อแทรกลงในตำแหน่งที่ถูกต้อง มีประสิทธิภาพสูงมาก O(n) เมื่อข้อมูลเกือบเรียงอยู่แล้ว

4. Quick Sort

ใช้เทคนิค Divide and Conquer โดยเลือก Pivot แล้วแบ่งข้อมูล: ค่าน้อยกว่าไปซ้าย ค่ามากกว่าไปขวา ทำงานได้รวดเร็วโดยเฉลี่ย O(n log n)

1. โหมดบททดสอบ (Algorithm Puzzle)

  • Bubble Sort: ดูคู่ที่ไฮไลท์ ถ้าซ้าย > ขวา ให้กด "สลับ", ถ้าไม่ใช่ให้กด "ข้าม"
  • Selection Sort: สแกนหาตัวที่ค่าน้อยที่สุดในโซนที่ยังไม่เรียง คลิกเลือกตัวนั้น แล้วกดยืนยัน
  • Insertion Sort: นำแท่ง Key เลื่อนแทรกลงในตำแหน่งที่ถูกต้องในโซนที่จัดเรียงแล้ว
  • Quick Sort: สังเกตค่า Pivot แล้วแยกว่าแท่งที่เลือกควรไปอยู่ฝั่งซ้าย (< Pivot) หรือขวา (≥ Pivot)

2. โหมดแข่งกับ AI (Race Duel)

คลิกเลือก 2 แท่งใดๆ ในเลนของคุณเพื่อสลับตำแหน่ง (Swap) จัดเรียงจากน้อยไปหามากให้เสร็จก่อน AI
