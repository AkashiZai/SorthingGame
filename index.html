📖 คัมภีร์สรุป Sorting Algorithms & Big-O

Sorting Algorithm คือขั้นตอนวิธีในการเรียงลำดับชุดข้อมูลให้อยู่ในลำดับที่ต้องการ (เช่น จากน้อยไปหามาก) แต่ละอัลกอริทึมมีจุดเด่นและประสิทธิภาพต่างกัน:

Algorithm Best Case Average Case Worst Case Space Complexity
Bubble Sort O(n) O(n²) O(n²) O(1)
Selection Sort O(n²) O(n²) O(n²) O(1)
Insertion Sort O(n) O(n²) O(n²) O(1)
Quick Sort O(n log n) O(n log n) O(n²) O(log n)

1. Bubble Sort (การเรียงแบบฟองสบู่)

เปรียบเทียบคู่ข้อมูลที่อยู่ติดกัน (Adjacent pairs) ถ้าตัวหน้ามากกว่าตัวหลังจะสลับที่กัน ทำซ้ำไปเรื่อยๆ จนกระทั่งค่าที่มากที่สุดจะ "ลอยตัว" ไปอยู่ด้านท้ายสุดทีละรอบ เหมาะกับข้อมูลชุดเล็กหรือเกือบเรียงแล้ว

2. Selection Sort (การเรียงแบบคัดเลือก)

ในแต่ละรอบ จะค้นหา "ค่าน้อยที่สุด" (Minimum) จากส่วนที่ยังไม่ได้จัดเรียง แล้วนำมาสลับกับตำแหน่งแรกสุดของส่วนนั้นเสมอ มีจำนวนการ Swap น้อยที่สุดคือ O(n) แต่ต้องเปรียบเทียบ O(n²) ทุกกรณี

3. Insertion Sort (การเรียงแบบแทรก)

ทำงานเหมือนการเรียงไพ่ในมือ โดยหยิบสมาชิกทีละตัว แล้วเลื่อนสมาชิกที่มีค่ามากกว่าไปข้างหลังเพื่อ "แทรก" สมาชิกนั้นลงในตำแหน่งที่ถูกต้อง มีประสิทธิภาพสูงมาก ($O(n)$) เมื่อข้อมูลเกือบเรียงอยู่แล้ว

4. Quick Sort (การเรียงแบบรวดเร็ว)

ใช้เทคนิคแบ่งแยกและเอาชนะ (Divide and Conquer) โดยเลือกสมาชิกตัวหนึ่งเป็นแกนหลัก (Pivot) แล้วจัดกลุ่มข้อมูล: ตัวที่น้อยกว่า Pivot ไปไว้ทางซ้าย และตัวที่มากกว่าไปไว้ทางขวา จากนั้นทำซ้ำกับแต่ละฝั่ง ทำงานได้รวดเร็วมากโดยเฉลี่ย $O(n \log n)$

🎮 กติกาและวิธีเล่น SortCraft

1. โหมดบททดสอบ (Academy Trials)

คุณจะสวมบทบาทเป็นอัลกอริทึมตัวนั้นจริงๆ โดยต้องทำตามกติกาของแต่ละตัว:

  • Bubble Sort: ระบบจะไฮไลท์คู่ที่ติดกัน ให้คุณดูว่าตัวซ้าย > ขวาหรือไม่ ถ้าใช่กด "สลับ", ถ้าไม่ใช่กด "ข้าม"
  • Selection Sort: สแกนหาขวดที่ค่าน้อยที่สุดในโซนที่ยังไม่เรียง คลิกเลือกขวดนั้น แล้วกด "วางที่หัวแถว"
  • Insertion Sort: นำขวดที่หยิบมา (Key) เลื่อนแทรกลงในตำแหน่งที่ถูกต้องในโซนที่จัดเรียงแล้ว
  • Quick Sort: สังเกตค่า Pivot แล้วแยกว่าขวดที่เลือกควรไปอยู่ฝั่ง "ซ้าย (< Pivot)" หรือ "ขวา (> Pivot)"

2. โหมดประลอง AI (Race Duel)

แข่งความเร็วกับบอทอัลกอริทึม! คลิกเลือก 2 ขวดใดๆ ในเลนของคุณเพื่อสลับที่กัน (Swap) จนกว่าจะเรียงจากน้อยไปมากครบทั้งหมด ใครเสร็จก่อนชนะ!

3. โหมดนักวางแผน (Strategist)

อ่านโจทย์สถานการณ์ชุดข้อมูล แล้วเลือกการ์ด Sorting Algorithm ที่เหมาะสมที่สุดเพื่อลดจำนวน Operations ให้ต่ำที่สุดและคว้า 3 ดาว!
