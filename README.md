# SortLab - Interactive Sorting Algorithm Game
> โครงการเกมการศึกษาด้านวิทยาการคอมพิวเตอร์: Interactive Sorting Algorithm Game (Single-file Web Application)

---

## 1. วัตถุประสงค์และแนวคิดของเกม (Concept)

**SortLab** เป็นเกมจำลองการแก้ปัญหาเชิงอัลกอริทึม (Algorithmic Puzzle Game) ที่พัฒนาขึ้นโดยให้ **Sorting Algorithms เป็นแกนหลักของการเล่น (Core Game Mechanic)** โดยผู้เล่นจะได้สวมบทบาทปฏิบัติตามกฎและตรรกะของอัลกอริทึมในการจัดเรียงข้อมูล เพื่อให้ผู้เล่นได้เข้าใจกลไกและขั้นตอนการทำงานของอัลกอริทึมอย่างแท้จริงจากการเล่น

### ปรัชญาการออกแบบ (Design Philosophy)
- **Focused & Minimalist:** ออกแบบสไตล์ Modern Developer Interface (Dark Slate/Zinc Theme) สะอาดตา ชัดเจน ปราศจากลูกเล่นที่ไม่จำเป็น (No AI Slop / No Fluff)
- **Mechanics as Algorithms:** กติกาในเกมถูกจำลองมาจากข้อจำกัดทางคณิตศาสตร์และตรรกะของอัลกอริทึมโดยตรง
- **Multi-Algorithm Support:** รองรับการจัดเรียงถึง 4 อัลกอริทึมหลัก (Bubble, Selection, Insertion, Quick Sort)
- **Educational Big-O Grounding:** ผู้เล่นจะได้เห็นความแตกต่างของจำนวนการเปรียบเทียบ (Comparisons) และการสลับตำแหน่ง (Swaps) ของแต่ละอัลกอริทึมในเชิงประจักษ์ พร้อม Live Code & Complexity Inspector

## 2. ระบบเกมเพลย์และอัลกอริทึมที่เลือกเล่นได้ (Game Mechanics & Algorithms)

ผู้เล่นสามารถเลือกเล่นและเรียนรู้อัลกอริทึมต่างๆ ได้อย่างอิสระผ่านเมนูด้านบน พร้อมปรับขนาดชุดข้อมูลได้ (5, 6 หรือ 8 ตัวเลข):

### 1. Bubble Sort (การเปรียบเทียบคู่ติดกัน)
- **กติกา:** เปรียบเทียบสมาชิกคู่ติดกัน $arr[j]$ และ $arr[j+1]$
- **การตัดสินใจของผู้เล่น:** 
  - หากตัวซ้ายมากกว่าตัวขวา $\rightarrow$ กดปุ่ม **"สลับ (Swap)"**
  - หากเรียงถูกต้องแล้ว $\rightarrow$ กดปุ่ม **"ข้าม (Keep)"**
- **ผลลัพธ์:** เมื่อจบรอบ ค่าที่มากที่สุดจะถูกล็อคสถานะไว้ที่ท้ายแถวทีละตำแหน่ง

### 2. Selection Sort (การค้นหาค่าน้อยที่สุด)
- **กติกา:** สแกนค้นหาค่าที่น้อยที่สุด (Minimum) จากโซนข้อมูลที่ยังไม่จัดเรียง
- **การตัดสินใจของผู้เล่น:** 
  - คลิกเลือกแท่งข้อมูลที่คิดว่ามีค่าน้อยที่สุดในโซนขวา
  - กดปุ่ม **"ยืนยันสลับค่าน้อยสุด (Confirm Min Swap)"** เพื่อนำมาวางในตำแหน่งเริ่มต้นของรอบ
- **ผลลัพธ์:** สลับข้อมูลเพียง 1 ครั้งต่อ 1 รอบ ลดจำนวนการ Swaps ให้น้อยที่สุด

### 3. Insertion Sort (การแทรกข้อมูลลงในตำแหน่งที่ถูกต้อง)
- **กติกา:** ดึงข้อมูลทีละตัว ($Key$) แล้วเปรียบเทียบกับโซนที่จัดเรียงแล้วทางซ้ายมือ
- **การตัดสินใจของผู้เล่น:**
  - คลิกเลือกตำแหน่งในโซนซ้ายมือที่เหมาะสมในการแทรก $Key$
  - กดปุ่ม **"เลื่อนแทรก (Insert at Selected)"**
- **ผลลัพธ์:** จำลองขั้นตอนการจัดเรียงไพ่ในมือ เหมาะกับข้อมูลที่เกือบเรียงแล้ว

### 4. Quick Sort - Partitioning (การแบ่งส่วนด้วย Pivot)
- **กติกา:** กำหนดค่าหลัก ($Pivot$) ขึ้นมา แล้วสแกนข้อมูลทีละตัวเพื่อแบ่งกลุ่ม
- **การตัดสินใจของผู้เล่น:**
  - สังเกตแท่งข้อมูลปัจจุบันเทียบกับ $Pivot$
  - หากค่าน้อยกว่า $Pivot$ $\rightarrow$ กดปุ่ม **"ส่งไปโซนซ้าย (< Pivot)"**
  - หากค่ามากกว่าหรือเท่ากับ $Pivot$ $\rightarrow$ กดปุ่ม **"คงไว้โซนขวา (≥ Pivot)"**
- **ผลลัพธ์:** ข้อมูลจะถูกจัดกลุ่มและนำ $Pivot$ มาวางคั่นกลางอย่างถูกต้องตามหลัก Lomuto Partition

## 3. ตารางวิเคราะห์ Sorting Algorithms & Big-O Complexity

| Algorithm | Best Case | Average Case | Worst Case | Space Complexity | บทบาทและจุดเด่นในเกม |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Bubble Sort** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | สลับเฉพาะคู่ติดกัน เข้าใจขั้นตอนง่ายที่สุด |
| **Selection Sort** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ลดจำนวนการสลับข้อมูลให้น้อยที่สุด ($O(n)$ Swaps) |
| **Insertion Sort** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ทำงานได้เร็วที่สุดเมื่อข้อมูลเกือบเรียงสมบูรณ์ |
| **Quick Sort** | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | แบ่งส่วนข้อมูลด้วย Divide & Conquer รวดเร็วในภาพรวม |

## 4. สถาปัตยกรรมและเทคโนโลยี (Architecture)

- **Single-file Application (`index.html`):** รวม HTML5, CSS3, JavaScript และ Web Audio API ไว้ในไฟล์เดียวตามข้อกำหนด สะดวกต่อการเปิดเล่นและการนำขึ้นโฮสต์
- **Generator-based Engine (`function*`):** ใช้อนุพันธ์ JavaScript Generator ในการคำนวณและขับเคลื่อน Step-by-step Execution ของทุกอัลกอริทึมอย่างเป็นระเบียบ
- **Web Audio API:** สังเคราะห์เสียงสั้นแบบมินิมอล (Soft Sine / Triangle Tones) แบบ Native โดยไม่ต้องดาวน์โหลดไฟล์เสียงจากภายนอก
- **Zero External Dependencies:** ไม่พึ่งพา Library หรือ CDN ภายนอก ทำงานได้ 100% แม้ไม่มีอินเทอร์เน็ต

     - Source: `Deploy from a branch`
     - Branch: เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
   - ตัวเกมจะพร้อมให้เข้าเล่นผ่านลิงก์: `https://<username>.github.io/<repo-name>/`
