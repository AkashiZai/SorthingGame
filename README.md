# ⚗️ SortCraft: Potion Academy (มหาเวทจัดเรียงขวดมนตรา)
> โครงการเกมการศึกษาด้านวิทยาการคอมพิวเตอร์: Interactive Sorting Algorithm Game (Single-file Web Application)

---

## 🎯 1. วัตถุประสงค์และแนวคิดของเกม (Game Concept)

**SortCraft: Potion Academy** เป็นเกมแนว Puzzle & Strategy ผสมผสาน Simulation ที่ออกแบบมาเพื่อให้ผู้เล่นได้เรียนรู้และเข้าใจหลักการทำงานของ **Sorting Algorithms** อย่างแท้จริง โดยกลไกการเล่น (Game Mechanics) ถูกสร้างขึ้นมาจากตรรกะและข้อกำหนดของอัลกอริทึมโดยตรง ไม่ใช่เพียงแค่อนิเมชั่นประดับ

### 🏰 ธีมของเกม (Theme)
ผู้เล่นรับบทเป็น **"นักเรียนเวทมนตร์ฝึกหัดแห่งสถาบันเล่นแร่แปรธาตุ"** ที่ต้องจัดเรียง **"ขวดมนตรา (Potion Flasks)"** ตามระดับพลังเวท (1-99) จากน้อยไปหามาก โดยในแต่ละบทเรียนหรือการประลอง ผู้เล่นจะต้องปฏิบัติตามกฎของเวทมนตร์แต่ละบท ซึ่งก็คือข้อจำกัดและตรรกะของอัลกอริทึมจัดเรียงข้อมูลชนิดต่างๆ นั่นเอง

## 🎮 2. โหมดการเล่น (Game Modes)

ตัวเกมมีทั้งหมด **4 โหมดหลัก** เพื่อตอบโจทย์การเรียนรู้ที่ครอบคลุมทุกมิติ:

### 🧪 โหมดที่ 1: บททดสอบตามอัลกอริทึม (Academy Trials)
ผู้เล่นจะต้องสวมบทบาทเป็นอัลกอริทึมนั้นๆ และควบคุมการเปรียบเทียบ/สลับตามกฎเฉพาะ:
1. **Bubble Sort (ฟองอากาศเวท):** 
   - *กติกา:* ระบบจะไฮไลท์เปรียบเทียบเฉพาะ "คู่ขวดที่อยู่ติดกัน" ($j$ และ $j+1$) ผู้เล่นต้องพิจารณาว่าขวดซ้ายมากกว่าขวาหรือไม่ หากมากกว่าต้องกด **"สลับ (Swap)"** หากถูกต้องอยู่แล้วกด **"ข้าม (Keep)"**
   - *สิ่งที่ได้เรียนรู้:* เข้าใจว่าค่ามากจะค่อยๆ ลอยไปอยู่ท้ายแถวเหมือนฟองอากาศ และเข้าใจจำนวนรอบ $n-1$ รอบ
2. **Selection Sort (คัดเลือกค่าน้อยสุด):**
   - *กติกา:* ในแต่ละรอบ ผู้เล่นต้องกวาดสายตาหาขวดที่มี "ค่าน้อยที่สุด" ในโซนที่ยังไม่เรียง คลิกเลือกขวดนั้น แล้วกดปุ่มสั่งสลับมาไว้ที่ตำแหน่งหัวแถว
   - *สิ่งที่ได้เรียนรู้:* เข้าใจว่า Selection Sort การันตีจำนวนการสลับเพียง $O(n)$ ครั้งเสมอ
3. **Insertion Sort (จัดแทรกขวดเข้าที่):**
   - *กติกา:* หยิบขวดทีละใบ ($Key$) จากซ้ายไปขวา แล้วคลิกเลือกตำแหน่งในโซนฝั่งซ้ายที่จัดเรียงเรียบร้อยแล้ว เพื่อแทรกขวดลงในตำแหน่งที่ถูกต้อง
   - *สิ่งที่ได้เรียนรู้:* จำลองเหมือนการหยิบไพ่ขึ้นมาแทรกในมือ เห็นภาพการทำงานแบบ Adaptive
4. **Quick Sort (แบ่งมิติ Pivot):**
   - *กติกา:* สังเกตขวดที่เป็น $Pivot$ แกนกลาง แล้วตัดสินใจว่าขวดที่กำลังตรวจสอบควรถูกจัดไว้ฝั่งซ้าย ($< Pivot$) หรือฝั่งขวา ($\ge Pivot$) เพื่อทำการ Partition ให้สำเร็จ
   - *สิ่งที่ได้เรียนรู้:* เข้าใจกลยุทธ์ Divide & Conquer และหลักการทำงานของ Lomuto Partitioning

---

### ⚔️ โหมดที่ 2: ประลองความเร็วกับ AI (Race Duel - Man vs Machine)
- ผู้เล่นแข่งจัดเรียงขวดกับหุ่นยนต์ AI แบบ Real-time ในเลนขนานกัน
- ผู้เล่นสามารถคลิกเลือก 2 ขวดใดๆ เพื่อสลับตำแหน่งอย่างอิสระ
- หุ่นยนต์ AI จะประมวลผลทีละขั้นตอน (Step-by-step) ตามอัลกอริทึมที่เลือก (Bubble, Selection, Insertion หรือ Quick Sort) พร้อมปรับระดับความเร็วได้
- แสดงแถบ Progress Bar เปรียบเทียบความก้าวหน้าแบบสดๆ

---

### 🧠 โหมดที่ 3: นักวางแผนคัดเลือก Sort (The Strategist)
- ผู้เล่นจะพบกับโจทย์สถานการณ์ชุดข้อมูลในชีวิตจริง เช่น:
  - ข้อมูลที่เกือบเรียงสมบูรณ์อยู่แล้ว (Nearly Sorted) $\rightarrow$ เหมาะกับ **Insertion Sort** ($O(n)$)
  - ข้อมูลที่ต้องการลดจำนวนการ Swap ให้น้อยที่สุด $\rightarrow$ เหมาะกับ **Selection Sort** ($O(n)$ Swaps)
  - ข้อมูลสุ่มขนาดใหญ่ที่ต้องการความเร็วสูง $\rightarrow$ เหมาะกับ **Quick Sort** ($O(n \log n)$)
- ผู้เล่นต้องเลือกการ์ดอัลกอริทึมที่ทำต้นทุน (Operations) ได้เหมาะสมที่สุดตามทฤษฎี Big-O Complexity

---

### 🔬 โหมดที่ 4: ห้องทดลองอิสระ (Sandbox Lab)
- Visualizer เต็มรูปแบบ สามารถสุ่มข้อมูล (Random, Nearly Sorted, Reversed), ปรับขนาด (6, 10, 15 ขวด), และควบคุมการทำงานทีละก้าว (Step-by-step) หรือเล่นอัตโนมัติ (Play/Pause)
- มี Code Execution Tracer แสดงคำอธิบายการทำงานในแต่ละก้าวแบบละเอียด

## 📊 3. ตารางเปรียบเทียบ Sorting Algorithms & Big-O Complexity

| Algorithm | Best Case | Average Case | Worst Case | Space Complexity | จุดเด่นในเกม |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Bubble Sort** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | สลับเฉพาะคู่ติดกัน เข้าใจง่ายที่สุด |
| **Selection Sort** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | สลับข้อมูลน้อยที่สุด ($O(n)$ Swaps) |
| **Insertion Sort** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | เร็วที่สุดเมื่อข้อมูลเกือบเรียงแล้ว |
| **Quick Sort** | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | รวดเร็วด้วย Divide and Conquer |

## 🛠️ 4. สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Tech Stack)

เกมนี้พัฒนาเป็น **Single-file Application** (ไฟล์ `index.html` เพียงไฟล์เดียว) เพื่อความสะดวกในการโฮสต์และเปิดใช้งาน:
- **HTML5:** โครงสร้างเชิงความหมาย (Semantic HTML), Modals, HUD Cards
- **CSS3:** Modern Glassmorphism, CSS Variables, Flexbox/Grid, Animations, ขวดน้ำยาหลากสีพร้อมฟองอากาศ
- **JavaScript (Vanilla ES6+):**
  - **Generator Functions (`function*`):** ควบคุม Step-by-step Execution ของทุกอัลกอริทึมได้อย่างแม่นยำ 100%
  - **Web Audio API:** สังเคราะห์เสียงเอฟเฟกต์ (Chimes, Swaps, Fanfares, Pitches) แบบ Real-time ในเบราว์เซอร์ โดยไม่ต้องโหลดไฟล์เสียงภายนอกแม้แต่ไฟล์เดียว
  - **Zero External Dependencies:** ไม่พึ่งพา Library หรือ CDN ภายนอก ทำงานแบบ Offline ได้สมบูรณ์แบบ

## 🚀 5. วิธีเปิดเล่นและนำขึ้นโฮสต์ (How to Run & Deploy)

### วิธีที่ 1: เล่นบนเครื่องคอมพิวเตอร์ของคุณ (Local)
- ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Firefox, Safari) เล่นได้ทันที

### วิธีที่ 2: โฮสต์บน GitHub Pages (แนะนำ ฟรี 100%)
1. อัปโหลดไฟล์ `index.html` ขึ้น GitHub Repository ของคุณ
2. ไปที่ **Settings** > **Pages**
3. ที่หัวข้อ **Branch** เลือก `main` หรือ `master` แล้วกด **Save**
4. คุณจะได้รับ URL สำหรับเปิดเล่น เช่น `https://<username>.github.io/<repo-name>/`

### วิธีที่ 3: โฮสต์บน Netlify Drop (เสร็จใน 10 วินาที)
1. เข้าเว็บไซต์ [app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์ที่มีไฟล์ `index.html` ไปวางในหน้าเว็บ
3. จะได้รับ URL เล่นได้ทันทีโดยไม่ต้องตั้งค่าใดๆ
